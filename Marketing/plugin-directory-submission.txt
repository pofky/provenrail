=== PLUGIN NAME ===

provenrail-guard


=== DESCRIPTION ===

Undo for coding agents, including what a shell command did. A snapshot of the working tree before every tool call that can write, stored outside your repository, restored with /guard-undo and verified by tree hash. Plus a stop switch, a loop breaker, a warning when two sessions edit one file, and rules that refuse destructive commands. Offline, no account, runs on the system python3.

=== CATEGORY ===

security


=== IF THERE IS A LONGER "WHAT IT DOES" FIELD ===

Claude Code can rewind its own file edits, and its documentation says changes made by bash commands are not tracked. A shell command is how a working tree is actually lost: a recursive delete over uncommitted files, git checkout on a dirty tree, a script the agent wrote a minute earlier.

This plugin takes a snapshot of the working tree in the PreToolUse hook before every action that can write, Bash included. The snapshot goes into a second git object store under ~/.provenrail, outside the repository, so the user's own .git is never opened and nothing appears in git status. /guard-undo lists the checkpoints with what each action changed, restores one, and checks the result by tree hash before reporting it verified. A restore snapshots the current state first, so an undo can itself be undone. It does not cover gitignored files apart from root level .env files, files over 50 MiB, git history, or anything outside the repository, and it says so.

The same hook adds /guard-stop, which refuses every tool call from every agent on the machine until the user resumes; a loop breaker that asks after the same call or short cycle repeats 8 times back to back, a threshold taken from 3,186 real sessions; a question before one session edits a file another session wrote in the last 15 minutes; /guard-scan, which lists what in a cloned repository runs or steers an agent without asking; and 45 default rules that screen where a destructive command points. Everything runs locally with the Python already on the machine. Nothing is sent anywhere.

=== IF THERE IS AN "INSTALL" OR "USAGE" FIELD ===

/plugin marketplace add pofky/provenrail
/plugin install provenrail-guard@provenrail
/guard-budget 25

/guard-status shows what is armed and what it has actually stopped. /guard-rules prints every rule including the packs that are off by default. /guard-card produces a paste-safe summary with every operand stripped.
