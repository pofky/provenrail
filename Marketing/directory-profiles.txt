=== ONE LINE (for fields under 120 characters) ===

A spend cap and a delete policy for coding agents, enforced at the tool boundary and signed.


=== SHORT DESCRIPTION (50 words, for anywhere with a small field) ===

Provenrail gives a coding agent a daily spend cap it cannot argue its way past and a delete policy that holds in CI, where no human is there to approve a prompt. Every block and every prompt is signed into a record anyone can verify offline. Free plugin, no account.


=== LONG DESCRIPTION (for Crunchbase, AlternativeTo, StackShare) ===

Provenrail is a policy layer for coding agents. It runs at the tool boundary, before a command executes, and answers one question deterministically: should this call happen. 54 rules across 10 packs, 44 of them armed by default, cover the commands that actually destroy work, taken from public incident reports filed against coding agents: git reset --hard, git checkout -- ., git clean -fd, a framework database reset pointed at production, terraform destroy, DROP TABLE, a DELETE with no WHERE, a credential committed to a repository. The git rules read the repository first and stay silent when there is nothing uncommitted and nothing unpushed, because a prompt about nothing is how people learn to click through prompts.

Two things it adds that a permission prompt cannot. First, a spend cap: it prices the agent's own transcript and refuses the next tool call once the day's estimated cost crosses a number you set. No permission system has a dollar limit. Second, it runs where nobody is watching. An agent started with claude -p, or through the Agent SDK, Bedrock, Google Cloud's Agent Platform, Microsoft Foundry or Claude Platform on AWS, has no interactive classifier in front of it at all. Hooks still fire there, so the same policy applies in CI and on a schedule.

Every decision, allowed or denied, is canonicalised, Ed25519 signed and written into a hash-chained record. The record carries two independent chains, one from the agent and one from the receiving server, which must agree, so entries cannot be edited, reordered or removed after the fact without it showing. Record heads fold into an RFC 6962 Merkle tree published as signed transparency-log checkpoints, optionally countersigned by independent witnesses and timestamped by an RFC 3161 authority, which is the part you cannot issue to yourself.

Verification is MIT licensed, runs entirely offline, and trusts neither the agent, the server, nor Provenrail. Two independent verifiers, one in Python and one in JavaScript, are held to a frozen conformance suite both must agree on, and anyone can check a record in a browser with no account. The command pr report reads the transcripts your agent already wrote, prices them per project and per day, and replays every tool call against the rules to say how many would have been stopped. On the machine it was built on that was 79,883 tool calls and an estimated $7,863.51 in 31 days.

The guard is free and installs as a Claude Code plugin with nothing to set up. The paid plan, $9 a month, adds independent RFC 3161 timestamps and shareable proof links. The server is self-hostable, so records need never reach a third party.
