=== LONG DESCRIPTION (for Crunchbase, AlternativeTo, StackShare) ===

Provenrail is a tamper-evident audit trail and guardrail layer for AI agents. It intercepts an agent's tool calls and blocks destructive ones before execution, using 36 built-in rules across seven packs covering destructive commands, secrets, spending, production access, permissions, data exfiltration and blast radius. Every decision, allowed or denied, is canonicalised, signed with Ed25519 and written into a hash-chained record that leaves the agent's machine immediately.

The record carries two independent chains, one produced by the agent and one by the receiving server, which must agree, so entries cannot be edited, reordered or removed after the fact without detection. Record heads are folded into an RFC 6962 Merkle tree, published as signed transparency-log checkpoints, optionally countersigned by independent witnesses, and timestamped by an RFC 3161 authority.

Verification is open source under the MIT licence, runs entirely offline, and trusts neither the agent, the server, nor Provenrail. Two independent verifier implementations, one in Python and one in JavaScript, are held to a frozen conformance suite that both must agree on. Anyone can verify a record in a browser without an account.

Provenrail integrates with Claude Code as an installable plugin, and with OpenAI, Anthropic, LangChain and MCP through one-line instrumentation. The server is self-hostable, so records need never reach a third party. There is a free tier, and paid tiers add trusted timestamping, team access with roles and single sign-on, evidence exports and compliance reports.
