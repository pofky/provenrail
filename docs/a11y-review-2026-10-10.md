# Accessibility review, 2026-10-10 (WCAG 2.2 AA)

Verdict: PASS, after three defects were fixed.

Scope: all 19 pages in `web/` (18 at first, rerun after `undo-claude-code-changes.html` was added), at 375 px and 1280 px, dark and light colour schemes, served
from a local server and driven in Chrome through Playwright. Run directly by the session,
because no `accessibility-auditor` agent type exists in it.

## What was run
- axe-core 4.10.2, rule tags wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa: 38 page and width
  combinations, 0 violations after the fixes.
- Text contrast measured on every rendered text node against its composited background, in
  both schemes (axe left 153 contrast checks undecided, so they were computed instead):
  0 nodes under 4.5:1 (3:1 for large text) after the fixes.
- Keyboard: Tab through every page, 795 focus stops, each checked for a visible outline or
  ring: 0 without one after the fixes.
- Reflow at 320 px (WCAG 1.4.10, the same condition as 400% zoom at 1280): no page scrolls
  sideways.
- Target size (2.5.8): every control under 24 px was inspected. All are links inside a
  sentence (the inline exception) or 18 px checkboxes wrapped in a label that is the target.

## Defects found and fixed
1. `web/pricing.html:179`, WCAG 2.1.1 Keyboard. The sideways-scrolling comparison table could
   not be reached or scrolled from the keyboard. It is now a focusable labelled region with a
   focus ring (`web/pricing.html:47`).
2. `web/index.html:826`, WCAG 1.4.3 Contrast. The live verifier's VERIFIED label was 1.73:1
   in the light scheme, because its colour was tuned for the dark card only. Light-scheme
   colours added for both verdict states.
3. `web/account.html:57`, WCAG 2.4.7 Focus Visible. The email field showed focus only as a
   border colour change. It now shows the same ring as every other control.

## Not run
- A screen reader pass (VoiceOver). Landmarks, headings, labels and names were checked by
  axe only.
- The tampered state of the verifier in the light scheme was computed by formula (5.6:1),
  not rendered.
